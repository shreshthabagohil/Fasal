# Cross-lingual leakage audit — eval/heldout held-out set

`dataset/gold/*.jsonl` (244 rows, 8 languages) is what `eval/heldout/build_test_set.py`
starts from. D3_FLAGGED.md's automated paraphrase audit had already reduced the original
1,226-row gold set to these 244 rows by catching same-language near-duplicates
(embedding cosine >= 0.9 against the 69,670-row training set).

That audit did not check across languages. The KCC source data was machine-translated
into multiple target languages from the same underlying English query+answer
(`meta.orig_instruction_en`), so the same source record can land in `dataset/gold/`
under one language/id and an independent translation of it can land in the training
set under a different language/id -- no single-language text or id match, but it is
still the same underlying example the model was trained on.

Verified 2026-08-12 against the live `Algo-Nova/fasal-kcc-instruct` train split
(three signals checked: exact id, exact normalized instruction text, and
orig_instruction_en+output cross-lingual match). 0 hits on id/instruction-text,
